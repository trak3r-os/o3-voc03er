# voice at the input instead of the pad or lane. The voiceprint's mouth profile is drawn from the engine's parameters (the main loop never reads the unit's state), so
# it does NOT follow the live shape: the pictures show the key, the chord and that nothing breaks. The input is a 220 Hz tone, then 600 Hz, then none (a flat tone is
# no vowel, docs/ENGINE-REALISM.md); that the mouth follows a voice, and how it sounds, is the unit's. tests/mouth_test.cpp measures the mapping with synthetic vowels.
